## The project

Designing and building a centralised web platform for a film festival, handling
the audience experience, the filmmakers’ needs and the internal running of the event.

## Technologies

- **Front-end**: the interface is built with React.
- **Back-end**: Node.js and Express power all the business logic.
- **Database**: MySQL.
