## The project

Designing and building a full-stack web application for a solidarity economy,
letting a community of users trade services and talents without money, thanks to
a virtual currency: U-Coins.

## Technologies

- **Front-end**: the interface is built with React.
- **Back-end**: Node.js and Express power all the business logic.
- **Database**: MySQL.
